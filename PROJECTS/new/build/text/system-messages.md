# System Messages — ViralReword

## Loading State Label (skeleton tile area)

```

```

## General API Error

```
Something went wrong. Please try again.
```

## Network Error (fetch failed)

```
Can't reach the server. Check your connection and try again.
```

## Session Save Confirmation (silent — no UI message)

History is saved silently. No toast or confirmation is shown.

## Copy Success Confirmation (on tile copy button)

```
✓ Copied
```

Duration: 3 seconds. Replaces copy button label, not a separate toast.

## Tone Regeneration Loading State (single tile, during tone slider regeneration)

```
Rewriting…
```

(Displayed inline within the tile being regenerated only.)

## Sign-in Success (after auth redirect back to workspace)

No message shown. The Workspace loads normally with the tier indicator updated.
