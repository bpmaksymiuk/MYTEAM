# Guardrail and Ethics Messages — ViralReword

## Blocked Tile State

```
⛔ This variation was blocked.
```

Followed by the guardrail reason (supplied by the server), e.g.:
```
This version contained content that could not be verified as accurate.
```

## Advisory Warning Label (shown below the annotation on affected tiles)

```
⚠ {advisory label from server}
```

Example advisory labels (from server):
- `May overstate certainty`
- `Contains unverified statistic`
- `Urgency claim may mislead`

## Meaning Fidelity Warning Tooltip (for scores below 95%)

```
Meaning fidelity below 95% — review before posting.
```

## Transparency Disclosure Label (appended to copied text when toggle is enabled)

```
[AI-optimised version]
```

## Transparency Toggle Label (in workspace header)

```
Mark as AI-optimised
```

Tooltip on toggle:
```
When on, copied text will include "[AI-optimised version]" at the end.
```
