# TC-002 — HUD Display Labels

**Category:** UI
**DI:** DI-010 (HUDScene)

---

## HUD Text Strings

| Element | Display String | Notes |
|---------|---------------|-------|
| Score label prefix | SCORE: | Followed by numeric value, no comma separators |
| Lives label prefix | LIVES: | Followed by numeric value |
| Level label prefix | LEVEL: | Followed by level number |
| Time label prefix | TIME: | Followed by integer seconds remaining |

## Initial Values

| Element | Initial Value |
|---------|---------------|
| Score | 0 |
| Lives | 3 |
| Level | 1 |
| Time | 300 |
