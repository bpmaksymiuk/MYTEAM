# Save/Load text

- Slot card title: "Slot {N}"
- Empty slot label: "Empty"
- Saved slot label format: "Day {day} · {state} · saved {timestamp}"
  where {state} is the active event name or "stable", and {timestamp} is local time.
- Buttons: "Save", "Load", "Delete"
- Overwrite confirmation: "Overwrite slot {N}?"
- Delete confirmation: "Delete slot {N}?"
- Quota warning (≥ 4 MB): "Save data is approaching the 5 MB browser limit."
- Quota refusal (≥ 5 MB): "Cannot save: this state exceeds the 5 MB browser limit."
- Load success toast: "Slot {N} loaded."
