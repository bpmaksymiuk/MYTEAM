# Write the high level application vision below
###############################################################

An interactive Coulomb's law simulator with the following features: 

Charge placement: Users can place negative charges ("-") and positive charges ("+") on the canvas

Barriers: Charges bounce off of all lines drawn on the canvas. Users can draw on the canvas, and erase. 

Charge behavior: Charges spawn continuously from negative charges ("-") and are annihilated when they reach positive charges ("+")
Spawn rate control: A slider adjusts how frequently new charges spawn from negative charges

Physics: Charges move according to Coulomb's law (repel from "-", attract to "+"). The charges should repel eachother. The UI should have controls for simulation speed, charge strength, as well as other configurable features. 

User experience: Design the interface to be engaging and intuitive

Technology: Implement using web technology so that it works in a browser.
