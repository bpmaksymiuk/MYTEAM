RELEASE-NOTES:
- Version ID: v0.1.0-fps-browser-slice-2026-04-01
- Summary of features implemented.
  - Implemented browser-playable FPS prototype using Three.js in src/index.html, src/styles.css, and src/app.js.
  - Added first-person movement with mouse look, WASD, jump, and sprint.
  - Added dual-weapon system: rifle (hitscan) and launcher (projectile pool) with weapon switching and ammo tracking.
  - Added two enemy archetypes (melee and ranged) with pursuit and attack logic.
  - Added player health/damage, game over flow, and restart behavior.
  - Added pickups (health and ammo), hazards, and one complete arena map with enemy spawn points.
  - Added HUD (health, weapon, ammo, kills, score, FPS), crosshair, main menu, pause menu, and game-over overlay.
  - Added configurable movement keybindings and optional gamepad polling.
  - Added optional procedural audio cues with mute toggle.
  - Added basic performance protections: bounded delta time and projectile pooling.
